# 冠军伤害计算器 · Champions Damage Calc

宝可梦冠军（Pokémon Champions）M-C 规则伤害计算器的网页版 App。

- 单打 / 双打切换，等级 50、个体值 31 固定，0–32 能力点滑动条
- 选宝可梦后自动套用常用配置，道具、招式、性格旁标注采用率
- 中文 / 日本語 / English 三语切换
- 可添加到手机主屏幕，离线也能用
